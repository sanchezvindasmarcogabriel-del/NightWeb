# Nightweb

Archivo colectivo de lo inexplicable: una red social ficticia donde las personas comparten pesadillas, misterios y experiencias paranormales.

**Autor:** Marco Sánchez Vindas · Sección 10-4 · Proyecto I, II Semestre 2026

## Descripción
Nightweb es una página web interactiva hecha con HTML, CSS y JavaScript. Permite publicar relatos con imagen opcional, dar "Me gusta", filtrar y buscar publicaciones. Es el proyecto de Programación para Web, versionado con Git y GitHub para Diseño de Software.

## Características principales
- Publicaciones con usuario, título, categoría, fecha, imagen opcional y contador de "Me gusta".
- Seis categorías: Alucinación, Misterio, Experiencia, Manifestación, Pesadilla y Ultrapesadilla.
- Validación del formulario: título obligatorio y mínimo 50 caracteres en el relato.
- Filtro por categoría, buscador y orden de publicaciones.
- Eliminar publicaciones propias.
- Perfil con estadísticas y lista de publicaciones.
- Diseño responsivo con barra lateral fija.
- Las publicaciones se guardan en el navegador (localStorage).

## Tecnologías
HTML5, CSS3 (Flexbox y Grid), JavaScript, Git y GitHub.

## Estructura del proyecto
- `index.html`: estructura de la página.
- `css/style.css`: estilos y diseño responsivo.
- `js/main.js`: lógica de la red social.
- `img/`: logo e imágenes de las publicaciones.
- `.gitignore`: archivos excluidos del control de versiones.

## Cómo ejecutarlo
1. Clona el repositorio.
2. Abre `index.html` en el navegador.

## Control de versiones
Ramas de trabajo: `html`, `css`, `js` y `fix/titulo`, integradas en `main` con `merge`. Versión final: `v1.0.0`.
